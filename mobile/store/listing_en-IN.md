# Axythic store listing (English — India)

## App name

Axythic

## Short description

Mobile procurement, invoice capture and store operations for Axythic teams.

## Full description

Axythic is the field companion for authorised store teams. It brings daily
procurement and store operations to a mobile-first workspace designed for work
at the counter, in the stock room and while moving between branches.

Use Axythic to:

- photograph supplier invoices and review extracted details;
- monitor store synchronisation and pending offline work;
- review purchase quantities and assign suppliers;
- compare final orders between procurement refreshes;
- monitor internal stock distribution runs;
- access operational reports, supplier information and cycle controls.

Offline-safe workflows preserve supported edits on the device and send them in
order when connectivity returns. Access requires an Axythic organisation
account and an authorised store assignment.

## Suggested screenshot sequence

1. Dashboard — store context and daily status
2. Invoice capture — camera and page filmstrip
3. Invoice review — findings and corrected line items
4. Purchase Workspace — quantities and supplier assignment
5. Refresh Compare — clear order changes
6. Sync Live — store health and progress

Use only anonymised demonstration data. Do not show real invoices, credentials,
phone numbers, supplier pricing or tenant identifiers.

## Review notes draft

This is an authenticated enterprise operations client. Review credentials and a
test tenant must be supplied privately in the store review portal. Camera access
is used to photograph supplier invoices; photo-library access lets the reviewer
choose an existing invoice image. Face ID/biometric unlock is optional.
